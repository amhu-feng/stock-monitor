# 股票盯盘助手 · 本地个人版
## 使用说明

**定位**：纯本地个人行情监控工具。无账号、无登录、无自动下单。
所有数据只存本机，不上传任何服务器。所有提醒仅为信息参考，请由你本人在券商软件手动交易。

---

### 一、启动方式
- 源码运行：在项目根目录执行  `python main.py`
- 打包版：双击 `dist/股票盯盘助手.exe`（单文件绿色版，首次启动稍慢属正常）

### 二、七个功能页签
1. **① 自选行情监控**：实时行情表 + 选中股票显示日K（近60日）+ 信号提醒栏。可手动刷新、添加自选代码。**表格分页显示（每页20/30/50/100条）+ 顶部"显示字号"即时调整**，内容多也不卡。
2. **② 持仓交易记录**：新增/编辑/删除持仓；部分卖出、全部清仓自动记账到交易流水；同标的多笔持仓分开独立计算；实时刷新保本价、目标价、止损价、扣费净盈亏。**表格分页显示（每页20/30/50/100条）+ 顶部"显示字号"**。
3. **③ 手续费计算器**：临时试算一单（股数/买入价/卖出价/佣金率），实时给出买入成本、卖出费用、保本价、净盈亏。纯试算不入库。
4. **④ 策略&风控配置**：费率（佣金/最低佣金/过户费/印花税）、最小盈利阈值、轮询间隔、信号冷却、默认止损、声音开关、新闻参数，以及**界面与外观**（全局字体大小 9-18、浅色/深色主题）。保存即生效；界面设置可点"应用界面设置"即时预览。
5. **⑤ 新闻舆情中心**：宏观政策/行业/个股新闻自动采集（东方财富、新浪财经等多源，每条标注来源）；央视/国家规划类重点新闻标题标红【重点】；命中当前持仓的新闻，在该新闻下方用绿色子项列出关联股票代码与当前购入价；按类型/代码/关键词筛选；**信息分批编译显示 + 分页（每页30/60/100条可调），防止信息量过大卡死**；标记已读、手动批注、双击打开原文（无链接时自动用浏览器搜索标题）、导出MD/CSV。
6. **⑥ 大盘指数**：上证指数/深证成指/创业板指/沪深300/中证500/科创50 等主要指数的当天今开、昨收、最新(收盘)、涨跌幅、最高/最低、更新时间；随行情轮询自动刷新，可手动刷新。
7. **⑦ 走势分析**：输入股票代码或指数代码，可选 30/60/90/半年/一年/三年 周期，本地计算并绘制K线 + MA5/MA20/MA60 均线 + 成交量副图；标题给出周期涨跌幅、区间最高/最低、最新价。顶部有常用指数快捷按钮。

### 三、提醒规则（重要）
- 止盈提醒：现价 ≥ 目标卖出价（保本价×(1+最小盈利阈值)）→ 弹窗+声音
- 保本提示：现价 ≥ 保本价但未达目标 → 列表标灰，不弹窗
- 止损提醒：现价 ≤ 止损价 → 独立红色弹窗
- 同一标的在「信号冷却」分钟内不重复提醒

### 四、防卡死与数据源监测（重要）
- **手动刷新全部改为后台线程执行**，主界面永不卡死（不会再出现"未响应"）。
- 顶部"数据源监测"行实时显示：**读取中 / 状态：流畅 / 卡顿 / 无法获取 / 网络延迟：Xms**。
- **超时保护**：读取超过约12秒判定超时，停止本次；**间隔约3秒后自动重试，最多3次**。
- **3次仍失败**：明确显示原因，如"因网络延迟无法获取"或"因网站信息拦截或数据源异常无法获取"。
- 新闻列表**分批编译显示 + 分页**（每页30/60/100条可调），信息量大也不会卡界面。

### 四、数据与目录
- 数据存于 `data/stock.db`（SQLite：持仓、流水、新闻三张表），每日关闭时自动备份
- 配置存于 `data/config.json`
- 行情约15秒轮询、新闻约5分钟拉取、休市自动降频

### 五、安全边界
- 不存储任何证券账号/密码/验证码
- 不采集券商登录接口、不代下单
- 仅拉取公开财经行情与资讯

**免责声明**：本工具仅为个人行情分析辅助，不构成投资建议。股市有风险，历史回测不等于未来收益，AI/策略信号不保证盈利。所有交易决策与盈亏由你本人承担。
