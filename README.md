# 股票盯盘助手 · 本地个人版 (Stock Monitor)

> 纯本地个人股票行情监控工具。**无账号、无登录、无自动下单**。所有数据只存本机，不上传任何服务器；所有提醒仅为信息参考，由用户本人在券商软件手动交易。

---

## 📌 项目简介

一款基于 Python + Tkinter 的 Windows 桌面个人股票监控应用，覆盖 **自选行情、持仓盈亏、手续费计算、策略风控、新闻舆情、大盘指数、走势分析** 七个功能页签。行情与资讯通过公开财经接口（东方财富、新浪财经等多源）拉取，内置数据源自动降级、后台拉取防卡死、超时重试与状态监测。

**设计红线**：不托管证券账户、不采集券商登录接口、不代下单、不存储任何账号/密码/验证码、数据仅存本机。

## ✨ 功能特性

### 七个功能页签

| 页签 | 功能 |
| --- | --- |
| ① 自选行情监控 | 实时行情表（东方财富→新浪多源降级）+ 选中股票显示日K（近60日）+ 信号提醒；表格分页（每页20/30/50/100条）+ 显示字号即时调整 |
| ② 持仓交易记录 | 增删改、部分卖出、全部清仓自动记账到流水；同标的多笔分开独立计算；实时刷新保本价/目标价/止损价/扣费净盈亏；分页显示 + 字号调整 |
| ③ 手续费计算器 | 临时试算一单（股数/买入价/卖出价/佣金率），实时给买入成本、卖出费用、保本价、净盈亏，纯试算不入库 |
| ④ 策略 & 风控配置 | 费率（佣金/最低佣金/过户费/印花税）、最小盈利阈值、轮询间隔、信号冷却、默认止损、声音开关、新闻参数；**界面与外观**（全局字体9–18、浅色/深色主题） |
| ⑤ 新闻舆情中心 | 宏观/行业/个股新闻多源采集并标注来源；央视/国家规划重点新闻标题标红【重点】；命中持仓的新闻以绿色子项列出关联代码与购入价；**分批编译 + 分页（30/60/100条）防卡死**；标记已读、批注、双击打开原文、导出MD/CSV |
| ⑥ 大盘指数 | 上证/深证/创业板/沪深300/中证500/科创50 当天今开、昨收、最新、涨跌幅、最高/最低、时间 |
| ⑦ 走势分析 | 输入股票/指数代码，30/60/90/半年/一年/三年周期，本地计算并绘制 K线 + MA5/20/60 均线 + 成交量副图，含区间涨跌幅/高低点 |

### 提醒规则
- 止盈提醒：现价 ≥ 目标卖出价（保本价×(1+最小盈利阈值)）→ 弹窗+声音
- 保本提示：现价 ≥ 保本价未达目标 → 列表标灰，不弹窗
- 止损提醒：现价 ≤ 止损价 → 独立红色弹窗
- 同一标的在「信号冷却」分钟内不重复提醒

### 防卡死与数据源监测
- 手动刷新全部后台线程执行，主界面永不卡死
- 顶部"数据源监测"行实时显示：读取中 / 状态：流畅 / 卡顿 / 无法获取 / 网络延迟
- 超时保护（约12s）→ 间隔重试（约3s，最多3次）→ 失败显示原因
- 新闻分批编译 + 分页，信息量大不卡界面

## 🚀 安装与运行

### 环境要求
- Python 3.10+（开发运行，需完整版含 Tkinter）
- 依赖：`akshare`、`matplotlib`、`pandas`、`PyInstaller`（仅打包需要）

### 源码运行
```bash
git clone https://github.com/amhu-feng/stock-monitor.git
cd stock-monitor
pip install akshare matplotlib pandas pyinstaller
python main.py
```

### 打包为 Windows 单文件 exe
项目已提供 `build.ps1`（使用 `--onefile --windowed --collect-all akshare`）：
```powershell
.\build.ps1
# 产物：dist/股票盯盘助手.exe（单文件绿色版，双击即用，首次启动稍慢属正常）
```

## 🔧 技术栈

- **语言/界面**：Python 3、Tkinter / ttk（clam 主题，支持浅色/深色）
- **数据**：akshare（东方财富、新浪财经等多源）、pandas
- **图表**：matplotlib（K线 + 均线 + 成交量副图，中文用 Microsoft YaHei）
- **存储**：SQLite（本地 `data/stock.db`），每日自动备份
- **打包**：PyInstaller（onefile）
